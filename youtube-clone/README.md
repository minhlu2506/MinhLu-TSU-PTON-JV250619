# YouTube Homepage Clone

A lightweight static clone of the YouTube homepage using HTML, CSS, and JavaScript.

## Run locally

- Open `index.html` directly in your browser, or
- Serve the directory and open `http://localhost:8000`:

```bash
python3 -m http.server 8000 --directory /workspace/youtube-clone
```

## Features

- Sticky header with search bar and actions
- Collapsible sidebar navigation
- Category chips bar
- Responsive video grid with thumbnails and metadata
- Sample data rendered via JavaScript
